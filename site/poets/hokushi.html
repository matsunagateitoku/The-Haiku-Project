Selected poems
馬洗ふ川すそ闇き水鶏かな
Uma arau / kawa suso kuraki / kuina kana
Washing the horse / at a dark river-mouth, / a water-rail.
Summer · 水鶏 Kuina — Water-Rail [Summer Dobutsu]
釣竿に鮎のあはれや水はなれ
Tsuri zao ni / ayu no aware ya / mizu banare
On the pole, / the ayu pathetic — / leaving the water.
Summer · 鮎 Ayu — Sweet-Fish [Summer Dobutsu]
あぢさゐの　花や手鞠の　染めかへし
Ajisai no / hana ya temari no / some kaeshi
Hydrangea / flowers — like hand-balls / re-dyed.
Summer · 紫陽花 Ajisai — Hydrangea [Summer / Shokubutsu]
若竹や　竹より出でて　青き事
Wakatake ya / take yori idete / aoki koto
Young bamboo — / coming out from bamboo, / so green!
Summer · 若竹 Waketake — Young Bamboo [Summer / Shokubutsu]
